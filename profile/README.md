volee is an open-source terminal tool, written in Rust, for people who run many
coding agents at once, Claude Code sessions first.

- **See every agent** on the machine: state, repository, branch and worktree,
  whoever started it.
- **Answer what needs you first**: permission prompts, questions and finished
  work, sorted by urgency.
- **Review what they did**: commits, diffs, push state, pull request and checks.
- **Follow the conversation**: agents message each other and you through an MCP
  server, shown as threads and as a live graph.
- **Run missions**: a goal across several repositories, split by a coordinator
  agent, delivered by workers and checked by code.
