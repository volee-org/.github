# .github

Organization-wide files for [volee-org](https://github.com/volee-org).

- [`profile/README.md`](profile/README.md) is the profile shown on the
  organization's page.
- [`profile/assets/`](profile/assets) holds the wordmarks it uses: copies of
  the brand assets kept in `assets/brand` of
  [volee-org/volee](https://github.com/volee-org/volee), where the project
  itself lives.
